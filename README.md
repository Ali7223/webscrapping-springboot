# Spring Boot Book Scraper

A simple Spring Boot project that scrapes book data from [Books to Scrape](https://books.toscrape.com)  
and displays it using **Thymeleaf** and **PostgreSQL**.

# Features
- Web scraping using **Jsoup**
- Saves data into **PostgreSQL**
- Clean UI built with **Thymeleaf**
- Manual scraping trigger with one click

# Tech Stack
- Java 17+
- Spring Boot
- Jsoup
- PostgreSQL
- Thymeleaf
- Maven
